# 学习通AI自动刷课技能

这是供支持 SKILL.md 技能的 AI agent 使用的学习通课程辅助工具，包含浏览器自动化脚本和运行参考。支持情况取决于平台页面、账号和 agent 的本机操作权限，无法保证所有课程均可完成。

## 交给 AI agent 的安装指令

复制仓库地址并发送：

> 请读取本仓库 README.md 和 SKILL.md，先检查操作系统、Node.js 和 Chrome/Edge，再把完整目录安装到你支持的个人技能目录，保留 scripts 与 references；不要覆盖已有同名技能，先核对内容。重新加载技能（如你的客户端要求重启，请告诉我），确认能够读取 SKILL.md 与引用文件。不要索取或记录我的密码、Cookie。安装完成后，告诉我如何调用，并等待我指定课程和登录。

技能名：`chaoxing-course-automation`。不同 AI 客户端的技能目录和重载方式不同，按客户端官方规则操作；只有读取文件的 agent 也可按 SKILL.md 手动执行，但不能假称已注册为原生技能。

## 运行条件和使用

- 当前脚本面向 Windows，需 Node.js 22 或更高版本（内置 fetch 与 WebSocket）、Chrome 或 Edge，且 agent 能运行本地命令和访问浏览器调试端口。
- 用户自行在专用浏览器窗口登录；验证码由本人处理。浏览器 profile 包含登录态，请放在技能目录之外，不要共享或提交。
- 告诉 agent 想处理的课程。先列出课程、确认范围，再执行视频和文档任务，最后以平台页面的实际状态核对。
- 考试和提交可能有学校规定及不可逆后果，按课程要求使用；交卷前由用户确认。遇监考或验证码，遵守平台要求。
- `cx-docs.mjs` 是旧版辅助脚本，当前依赖工作目录中的 `cookies.txt` 和显式 `--course`、`--clazz`、`--cpi`，未实现自动提取登录信息。不要把 Cookie 发给 AI、加入仓库或作为部署前提。可先尝试 `cx-play.mjs` 支持的视频与文档流程；文档功能需按具体课程实际验证。

## 验证状态

发布前可运行 `node scripts/check-portability.mjs` 与 `node scripts/check-bom.mjs`，以及逐文件 `node --check`。这些只验证静态语法或部分规则，不能证明登录、课程处理、考试或提交可用。真实使用须在本人授权的账号和课程上验证。

运行会产生 profile、课程清单、答卷、日志等私人数据，存放在仓库外；不要上传。仓库为源码，无需提供密码。
